# CPP03 - 42 | [FRENCH VERSION] *english below*

## 📚 Description

Le module CPP03 approfondit les concepts de **l'héritage** en C++.
À travers une série d'exercices, il introduit les classes dérivées, la réutilisation de code, ainsi que les relations entre classes en construisant progressivement une hiérarchie autour de différents robots de combat.

---

## 🛠️ Notions abordées

* Héritage
* Classes de base et classes dérivées
* Redéfinition de fonctions
* Constructeurs et destructeurs dans une hiérarchie de classes
* Héritage multiple
* Appel des constructeurs des classes parentes

---

## 📂 Exercices

* **ex00** : Aaaaand... OPEN!
* **ex01** : Serena, my love!
* **ex02** : Repetitive work
* **ex03** : Now it's weird!

| Commande      | Description                                                            |
| ------------- | ---------------------------------------------------------------------- |

| `make fclean` | Supprime les fichiers objets **et** l'exécutable                       |
